# Бутылочка — многопользовательская игра для ВКонтакте

Мини-приложение ВКонтакте ([vk.com/app54583678](https://vk.com/app54583678)): классическая «бутылочка» с поцелуями
и вторая игра «Задания» — бутылочка выбирает игрока, он отвечает на вопрос. Игроки сидят за одним столом в реальном
времени, общаются в чате, дарят подарки, копят сердечки и рейтинг.

Проект прошёл путь от одиночной игры с локальными ботами до мультиплеера с сервером, аналитикой и экспериментами.
Продукт, приоритеты и решения по данным — мои; код написан вместе с ИИ-ассистентом (Claude), это видно в истории коммитов.

## Что умеет игра

- **Живые игроки за одним столом** — WebSocket, ход и таймеры на сервере, клиенту не доверяем
- **Две игры в одном приложении**: «Поцелуи» и «Задания», общий рейтинг и экономика
- **Боты, пока людей мало** — всегда помечены 🤖; уходят, когда за столом четверо живых; ведут себя «живо»:
  здороваются, дарят новичку подарок, коротко объясняют интерфейс в сценках — с лимитами, чтобы не забивать чат
- **Экономика**: сердечки за ответы и ежедневный бонус, подарки, VIP, оформление стола; все цены в одном каталоге на сервере
- **Модерация**: фильтр слов, жалобы с автоскрытием, блокировка, проверка ответов ИИ
- **Возвраты**: VIP за возвращение после суток без игры, уведомления ВК о вечернем сборе
- **Офлайн-режим**: если сервер недоступен, та же игра с ботами работает прямо в браузере

## Решения по данным

- **A/B-тест стартовой игры.** Новичков делили пополам: старт с «Поцелуев» или с «Заданий».
  Действие сделали 11 из 14 против 8 из 25 (p ≈ 0,008), время в игре вдвое выше — стартовой стала игра с поцелуями.
- **Воронка загрузки.** Клиент отмечает шаги (скрипт → профиль ВК → подключение → вход → стол).
  Нашли, что часть игроков отсекала проверка подписи ВК, — после исправления до стола доходит ~94% запусков.
- **Таймауты хода.** Почти половина игроков не успевала решить «поцеловать или нет» — решение вынесено в окно
  по центру стола, время увеличено, добавлена вибрация. Метрика всё ещё в работе.
- **Пары за столом.** Правило «бутылочка чаще указывает на живых» зацикливало игру на одной паре — исправлено,
  вес работает только когда крутит живой, и бутылочка не возвращается к тому, кто только что крутил.

## Стек

| Часть | Технологии |
|---|---|
| Клиент | React, Vite, VKUI, VK Bridge, Socket.IO |
| Сервер | Node.js, Fastify, Socket.IO, PostgreSQL |
| Инфраструктура | Docker Compose, Caddy (HTTPS), GitHub Pages для клиента |
| Аналитика | журнал событий в PostgreSQL, Яндекс Метрика |
| Тесты | node:test — игровая логика написана чистыми функциями (110+ тестов) |

## Что в этом репозитории

- `site/` — собранный клиент, который раздаёт GitHub Pages (это и есть адрес приложения в ВК)
- `legacy-singleplayer/` — исходники первой, одиночной версии игры (React + VKUI, без сервера)

Исходный код текущей версии (сервер и клиент) не публикуется — покажу по запросу.
